    How a photo is judged

    1. Converted and resized. The image becomes 3-channel RGB and is squeezed to 224 × 224 pixels, the size the model was trained on. Use Model's view to see it.
    2. Scaled to 0–1. Every pixel value is divided by 255, exactly like the training images.
    3. Scored. The network outputs a rotten score between 0 and 1. Above 0.5 the fruit is called rotten, otherwise fresh.

    Use the API directly

    Send the image as multipart form data in a field named file.

    curl -X POST http://localhost:8000/predict \
  -F "file=@apple.jpg"
    {
  "label": "Fresh",
  "confidence": 0.9618
}
